# Placeholder plant content

**The Uzbek text in `plants.json` is placeholder content and was machine-written.
It has NOT been reviewed by an agronomist and MUST be verified by a qualified
agronomist before this app is used for real advice.**

Plant names, growing seasons, watering guidance, disease labels and care tips are
all plausible-sounding approximations intended to exercise the UI during
development. Some of it is likely wrong for Uzbekistan's specific climate zones,
cultivars and local pest pressure.

`commonDiseases` doubles as the pool of disease labels the mock analyzer picks
from; the analyzer always adds `Sog'lom` ("healthy") itself, so it is not listed
here.

Replace or correct this file before shipping to real users.
